## Recent updates worth knowing

- **Copilot code review has a refreshed review experience**, and the **repository pull requests page** now has a redesigned UI in public preview — both aim to make reviewing and tracking PRs faster. ([github.blog/changelog](https://github.blog/changelog/))
- **Workflow execution protections** are now generally available in GitHub Actions, letting teams lock down what workflows can run and reducing the risk of malicious changes to CI/CD. ([github.blog/changelog](https://github.blog/changelog/))
- **Pull requests with exposed secrets can now be blocked from merging**, giving secret scanning real enforcement power instead of just alerts. ([github.blog/changelog](https://github.blog/changelog/))
- **Actions cache access can be controlled with a new `cache-mode` setting**, useful for tightening supply-chain security on workflow caches. ([github.blog/changelog](https://github.blog/changelog/))
- Copilot continues to ship fast: **agentic autofix for Code Quality findings**, an **impact dashboard** for feature engagement, and **cost/quality controls for auto model selection** all landed recently. ([github.blog/changelog](https://github.blog/changelog/))
- For hands-on learning, GitHub's **Copilot app for Beginners** series on the blog covers diff/terminal/browser workflows, running multiple agents, and writing effective prompts — a good on-ramp for new users. ([github.blog/latest](https://github.blog/latest/))
